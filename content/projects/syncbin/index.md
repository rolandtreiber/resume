SyncBin is a real-time text and file sharing tool for moving text, links and files quickly between devices.

## What I Built

- Created the product and web experience at syncbin.co.uk
- Built the Kotlin Multiplatform mobile application
- Designed session-based sharing, where each session acts like a simple shared bucket
- Added shared text editing plus file upload, download and delete workflows

## Product Focus

SyncBin is designed for the small but constant friction of moving information between machines. A session gives users a shared text field and file area that can be opened from multiple devices without turning the workflow into a chat thread, email draft or cloud-drive ceremony.
