Cloo is an outdoor team strategy mystery-solving game built for Cloo Entertainment. The project combined game tooling, mobile delivery and backend infrastructure.

## What I Built

- Planned, designed and built the game builder engine
- Designed and developed the mobile application
- Built deployment pipelines
- Created a high-availability session-manager microservice using Spring Boot
- Developed and deployed a Kotlin Multiplatform mobile application

## Technical Focus

The most important engineering challenge was coordinating live sessions reliably while supporting the game-builder workflow and mobile experience. The backend session service was built with Spring Boot, with mobile delivery handled through Kotlin Multiplatform.
