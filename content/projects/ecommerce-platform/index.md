Shoptopus is a comprehensive e-commerce platform built across PHP, Java and modern frontend tooling. It combines a Laravel backend API, Spring Boot services, React-based administration and Next.js customer-facing experiences.

## What I Built

- Planned, designed, architected and built the majority of the platform features
- Implemented complex API integrations including payment processors, ChatGPT and social media platforms
- Built and secured the server environment from the ground up
- Created Dockerized development and deployment workflows
- Configured Jenkins CI pipelines and automated test execution

## Technical Scope

The platform integrates with Stripe, ChatGPT, social media platforms, AWS and a self-hosted ELK stack. The backend API is built with Laravel 10, with Java/Spring Boot used where it fits the system architecture.

## Quality

The project is fully Dockerized and has a strong automated test base with 841 passing tests, no linter issues and no known errors at the time of the resume snapshot.
