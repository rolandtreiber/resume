K40 SVG Optimiser is a browser-based helper for preparing SVG files for K40 CO2 laser cutters using K40 Whisperer.

## What I Built

- Built an SVG workspace around the 300 mm x 200 mm K40 bed
- Added measuring, resizing, moving, rotating and selection tools
- Added one-click recoloring for K40 Whisperer cut and engrave operations
- Built layer-style element visibility, renaming, undo/redo and export flows
- Integrated SVG nesting behavior to arrange parts more efficiently

## Product Focus

The tool removes the repetitive preparation work that often sits between downloading or drawing an SVG and sending it to the laser. It keeps the workflow in the browser while still respecting the color conventions K40 Whisperer expects for vector cutting, vector engraving and raster engraving.
